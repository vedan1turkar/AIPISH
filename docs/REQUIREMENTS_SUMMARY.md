# Requirements summary (R1–R60)

This page summarises [requirements-matrix.md](requirements-matrix.md), the traceability matrix against the
PBL Review 0 document (Group G7). The matrix is the source of truth; the table and totals at the end of this
page are **generated** from it by `scripts/matrix_counts.py --write`, and CI fails if they drift.

**ID provenance.** R1–R40 come from an earlier project matrix. R41–R60 (marked `*`) were re-derived during the
P5 audit from PBL Review 0 §4.6, §5 and §8 and its recommended technology stack. The Review 0 document itself
is not in this repository, so the objective areas below group the matrix requirements by their titles; they do
not quote the original objective wording.

**Status codes.** VER = implemented and verified (tests plus a real-app run); IMP-U = implemented, verification
incomplete; PART = partial; STUB = stub only; MISS = missing; BLK = blocked by an external dependency.

## Blocked and deliberately not built

| ID | Requirement | Status | Reason | What would be needed |
|---|---|---|---|---|
| R35 | Background tasks / caching | MISS | Intel lookups and correlation recompute run synchronously; in-process and database caches only. Adequate at demo scale (correlation rebuild 3.9 s at 1,500 analyses). | A worker queue (for example Celery with Redis) and incremental correlation. |
| R36 | Email integration (IMAP/SMTP/Graph) | MISS | No test mailbox or Microsoft 365 tenant was available. | A mailbox or tenant, credential storage, and an ingestion worker (depends on R35). |
| R47 | MISP | BLK | No MISP instance available. | A MISP instance and API key; an adapter in `backend/app/intel/`. |
| R48 | MaxMind GeoIP2 | BLK | No licence key or database. | A GeoLite2/GeoIP2 database file and `MAXMIND_GEOIP2_DB`. |
| R50 | Neo4j | MISS | Deliberate: SQLite/PostgreSQL plus in-process NetworkX meets the current scale without another service. | A graph database only if cross-case graphs outgrow in-process computation. |
| R52 | Search (OpenSearch) | MISS | Deliberate: SQL `LIKE`/`ILIKE` search over analyses, cases, indicators and campaigns is enough at this scale; bodies are never indexed. | A search service and an indexing pipeline with the same masking rules. |
| R53 | OAuth 2.0 | BLK | No identity provider chosen; P5b is local password authentication with JWT. | An OIDC provider, client registration, and MFA. |
